# Scripture

Own canonical passage lookup, translation metadata, source provenance, and content
rights. Start with the current official public-domain Berean Standard Bible.
Record its edition/date, source URL, checksum, attribution, and versification when
importing it. Do not add a large corpus to this scaffold.

Expose approved text to clients and to study orchestration. Display rights and
permission to submit text to an LLM are separate capabilities; evaluate both for
each future licensed translation. A provider SDK must not decide these policies.

Reading should not depend on an LLM or a paid account. Decide how Bible text is
distributed and cached when implementing the reader.
