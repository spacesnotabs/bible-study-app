# Personal library

Own notes, highlights, saved findings, and questions to revisit. Store them on the
device first through `platform/storage`. Saving must not require login.

Future account sync should reuse stable local item IDs, retain passage and source
references, and offer an explicit import/merge of guest work. Do not overwrite or
delete local work merely because a user signs in, signs out, or loses connectivity.

Local storage, export, merge, and cloud backup are not implemented yet.
