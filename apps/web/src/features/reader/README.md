# Reader

Own passage navigation, translation selection, reading position, text selection,
and reading-mode presentation. Desktop/tablet can keep study beside the Bible;
phones can switch panes without losing their place.

Use `@bible-study/domain` for passage references and mode names. Use the storage
boundary for device preferences and position. The reader must remain usable
without an account or an available LLM service.

The current official Berean Standard Bible is the initial content choice. Its
importer, corpus, and distribution strategy have not been built.
